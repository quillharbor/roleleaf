# RoleLeaf Demo for Chrome — 0.5.7

1. Extract the ZIP to a permanent location.
2. Open chrome://extensions and enable Developer mode.
3. Choose Load unpacked and select this tipsy-exporter folder containing manifest.json.
4. Pin RoleLeaf, refresh Tipsy or Character.AI, sign in and start an export.

Do not move or delete the installed folder. To update, replace its contents with the new version, click Reload on the extension card, then refresh the source website. No Chrome Web Store automatic updates are provided. This is a desktop Chrome extension, not an Android Chrome extension.

RoleLeaf processes exports locally. It reads supported source-site responses under your existing access and saves a ZIP for each character. Keep source and export tabs open until completion. Current-conversation exports can include chat history; creator backups preserve available saved character settings without conversations. Missing fields and partial history remain explicitly reported.

Export ZIPs may contain private conversations and images. Keep them private. Download success does not prove complete history. Sign in again if a source session expires, and report only redacted errors.
