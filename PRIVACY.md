# Privacy

RoleLeaf processes exports locally. It connects to the supported source sites and their media services to load content under the user's existing access. The desktop and Android versions also display those sites in embedded browsers, where the sites' own privacy practices apply.

RoleLeaf does not include an application analytics or upload backend. Browser and WebView session storage may contain login state; exported files can contain private conversation text and images. Protect those files and choose carefully where to share them.

Do not include real exports, browser profiles or credentials in issue reports. Session reset and uninstall behavior depends on the platform; changing an application ID does not migrate the old application's session.
