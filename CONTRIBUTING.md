# Contributing

This repository is currently a private review candidate. A license must be selected before accepting public contributions.

For a bug report, include the platform, RoleLeaf version, minimal reproduction steps and a redacted error message. Use synthetic conversations and placeholder character IDs in fixtures. Do not post private messages, credentials, cookies or HAR files.

Before submitting a change, rebuild generated bundles with `npm run build`, run `npm test`, and check the affected application. Describe what changed, why, and what was actually tested. Generated bundles are committed so the unpacked Chrome extension can be loaded without a build step.
